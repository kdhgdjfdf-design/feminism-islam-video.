# النسوية والإسلام — مشروع Remotion

مشروع أولي عمودي 9:16 بمقاس 1080×1920 ومُدد 90 ثانية، بأسلوب وثائقي موشن جرافيك داكن وذهبي. النسخة الحالية رسوم ونصوص متحركة وصامتة؛ أضف التعليق الصوتي والموسيقى والمؤثرات بعد مراجعة النص والمصادر.

## التشغيل محليًا
يتطلب Node.js وبيئة تدعم Chromium وFFmpeg:
```bash
npm install
npm run studio
npm run render
```

## الرندر السحابي من GitHub Actions
1. افتح تبويب Actions في المستودع.
2. اختر Render Remotion video ثم Run workflow.
3. انتظر انتهاء الرندر.
4. نزّل Artifact باسم remotion-video للحصول على video.mp4.

لا ترفع كلمات مرور أو مفاتيح API إلى المستودع.
